# Project Plan: 20.04.2026 - Bookingkit Integration
**Objective:** Replace the internal booking system with a full Bookingkit integration and decommission Supabase/Stripe.

## Status: Completed (Final)

### **Phase 1: Foundation**
*   **Widget Isolation:** Created robust `BookingkitWidget.tsx` using `srcDoc` iframes and auto-height logic.
*   **Dark Mode:** Implemented real-time theme detection with CSS filters to match site depth (`#020617`) and protect images.
*   **Navigation:** Redesigned Navbar with modern dropdowns and standard `<a>` tags for reliable script initialization.

### **Phase 2: Granular Integration & Cleanup**
*   **Individual Item Mapping:** All 25 course and rental Experience IDs mapped in `docs/INDIVIDUAL_ITEMS_MAPPING.md`.
*   **Adventure Carousel:** Implemented high-performance infinite scrolling carousel on Home featuring all 25 items with verified photography and a sleek booking modal.
*   **Gruppen & Events:** Streamlined workflow where homepage boxes lead directly to `/gruppen/anfrage`.
*   **Inquiry Hub:** Integrated "Schulen" and "Firmen" widgets directly into the inquiry page with a consistent tabbed UI.
*   **Full Decommissioning:** 
    *   Removed all Supabase files, dependencies, and Auth logic.
    *   Removed all Stripe/Checkout logic.
    *   Admin dashboard now manages group inquiries via a local JSON fallback (`data/inquiries.json`).
*   **Legal & Polishing:** 
    *   Implemented GDPR Cookie Consent banner.
    *   Updated Impressum, Datenschutz, and AGB with real business info.
    *   Refined ModeToggle with snappy spring physics.
    *   Added real Google Maps location.
