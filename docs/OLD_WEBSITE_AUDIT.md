## 3. SEO Bug: "Event" Structured Data
**Issue:** Google Search Console reported 5 missing fields in the "Event" Schema: `url`, `performer`, `endDate`, `validFrom`, and `description`.

### **Findings:**
*   **Yoast SEO** is set to "WebPage" type for booking pages. It is **not** the source of the "Event" schema.
*   The schema is generated by the **Bookingkit Widget**.
*   The data is missing because the **Bookingkit Vendor Portal** profiles for these "Erlebnisse" (courses) are incomplete.

### **Required Fixes (In Bookingkit):**
*   **Description:** Fill the "Kurzbeschreibung" field.
*   **endDate:** Ensure a "Duration" is set for every course.
*   **Performer:** Verify "Anbieter-Name" is set to "Westufer Kemnade."
*   **URL:** Set the "Direct Link" to the corresponding WordPress page.
*   **validFrom:** Define the "Booking Period" in availability settings.
